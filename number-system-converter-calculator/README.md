# Number System Converter Calculator

A local multi-base arithmetic calculator for binary, octal, decimal, and hexadecimal values.

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:3000 to use the app.

## Features

- Convert values across binary, octal, decimal, and hexadecimal bases
- Perform addition, subtraction, multiplication, and division
- Validate input based on the selected number system
- Keep a local calculation history in the browser
